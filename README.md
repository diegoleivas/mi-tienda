Fileteando Ando 

Tienda online de productos de filete porteño, desarrollada como proyecto personal para aprender desarrollo web fullstack.

 Tecnologías

- **Frontend:** React
- **Backend:** Node.js + Express
- **Base de datos:** PostgreSQL (Neon)
- **Imágenes:** Cloudinary
- **Deploy frontend:** Vercel
- **Deploy backend:** Render

Funcionalidades

- Listado de productos
- Panel interno con login
- Alta, edición y eliminación de productos
- Carga de imágenes

Fileteando Ando 

Online store for Buenos Aires fileteado art products, built as a personal project to learn fullstack web development.

 Technologies

- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** PostgreSQL (Neon)
- **Images:** Cloudinary
- **Frontend deploy:** Vercel
- **Backend deploy:** Render

 Features

- Product listing
- Internal panel with login
- Create, edit and delete products
- Image upload
